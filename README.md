# warehouse
Приложение для учёта товара на складе магазина. Реализованы поступления, продажи, списания, расчёт прибыли по каждому товару за период, отчёт по просроченным списаниям и список товаров с близким сроком годности.
Реализовано на C++ с использованием PostgreSQL. Поддерживает работу через графический интерфейс (GUI) Win32.
# Возможности
Все денежные суммы отображаются в белорусских рублях (BYN) с обозначением **Br**.
- товары, категории, поставщики;
- поступление товара партиями: количество, закупочная цена, срок годности, накладная;
- разные закупочные цены у одного товара в разных партиях;
- продажа с автоматическим списанием остатка по партиям (FEFO — сначала истекает
  срок, затем более ранняя партия);
- списание товара с причинами `EXPIRED`, `DAMAGED`, `OTHER`;
- расчёт по каждой продаже:
  - выручки;
  - НДС;
  - себестоимости;
  - прибыли;
- отчёт «Прибыль по товарам» за выбранный период;
- отчёт «Просроченные списания»;
- отчёт «Скоро испортятся» с настраиваемым количеством дней;
- графический интерфейс на Win32 API (без Qt и сторонних UI-библиотек);
- хранение данных в PostgreSQL;
- параметризованные SQL-запросы и транзакции.
# Технологии
- C++20;
- Win32 API / Common Controls;
- PostgreSQL 14+;
- libpq (C API PostgreSQL);
- CMake 3.21+;
- Visual Studio 2022 (MSVC).
